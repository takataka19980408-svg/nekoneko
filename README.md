# 🐈 世界猫生ガチャ

地球上の猫 **約10億匹** のうち、1匹に生まれ変わるシミュレーター。
家猫・地域猫・野良猫・野生化したイエネコ・野生のネコ科・動物園——ぜんぶ混ぜて、
**ガチの生息数どおりの確率**で抽選します（エンジョイ緩和モードはありません）。

- 引いた猫は、国・境遇・毛並み・性別・目の色・変異まで個体ごとに生成
- **誕生画面でいったん停止**。国・種別・毛柄・境遇・性別・目の色と、
  **「地球約10億匹中の 約〇分の1（〇%）｜仲間は約〇匹」＋珍しいポイント** を主役に見せる
- **「🐾 この子の猫生を歩む」を押した瞬間からオート進行**がスタート
- 猫生を歩んでいる間はずっと見える **常時プロフィールバー（名札）**：
  `🇯🇵 日本・東京 ｜ キジトラ・メス ｜ 🏠 飼い猫 ｜ 約80分の1`。
  拾われたら `🏡 拾われて飼い猫に`、ボス猫・猫又・招き猫もその場で切りかわる
- その猫の **一生（猫生ハイライト）** を0歳から享年まで自動生成。
  **寿命に応じて歩数がスケール**（1歳≒8歩 / 5歳≒20歩 / 10歳≒35歩 / 15歳≒52歩 / 猫又≒66〜72歩）
- **季節がめぐる**：春🌸・夏🌻・秋🍁・冬❄️ のイベントと背景パーティクル、`3歳2か月` の細かい年齢表示
- イベント文章は **200本以上＋季節テンプレート**。1猫生のなかで同じ文は二度出ない
- 猫は **AI生成の2Dゲームイラスト**（13タイプ×子猫/成猫）。待機中は呼吸、タップで跳ねて鳴く
- 画像は背景を透過したPNGで、**体の内側は完全不透明**（`tools/cutout.py` が輪郭の内側の穴を埋め戻す＝「透明な猫」防止）。`tools/check_assets.py` と `tests/simulate.py` が全26枚を検査
- 拾われたときの **鈴付き首輪**は、26枚それぞれの首元座標（`js/catart.js` の `COLLAR` マップ）に合わせて子猫↔成猫で位置が切り替わる
- **子猫は小さく、成猫で「すくすく成長」** して画像とサイズが切り替わる
- 野良・地域猫は途中で **人に拾われる**ことがある。首輪がキラッと付いて、路地裏からあたたかいおうちへ
- ❤️たいりょく／🐟おなか／🍀うん のミニステータスが一歩ごとに変化（2択の結果がその後にも効く）
- **▶ オート進行**（1x=3.8秒 / 2x=1.9秒）。
  15歳の猫生（約52歩）が1xで約3分20秒＋2択の時間＝**約4〜5分**のボリューム
- **寿命は最後までわからない**：進捗は `🐾 12歩目` の現在値だけ。
  総歩数・「あと〇歩」・年齢の上限目盛りは出さない（お楽しみ）
- **2択は放置しても止まらない**：10秒（2xは5秒）のカウントダウンつき。
  タップすればその選択、時間切れなら `⏳ 時間切れでおまかせ選択！` で自動的に選んで続行。
  「⏸ 一時停止」中はカウントダウンも止まる
- **年をとる実感**：`3歳2か月` の細かい現在年齢と、通過した節目（🎂1歳・🎂3歳・🍂6歳・🎂10歳・👑15歳…）だけを表示。
  10歳「シニア期」・15歳「ご長寿猫」の演出と、日向ぼっこ色のステージ
- **2択で未来が変わる**：延命（+1〜3年・猫生が延びる）、ピンチ回避、野良から家族への分岐、ボス猫ルート
- **🏆 実績・称号 27個**と **📊 累計レコード**（累計転生・最長寿・拾われ回数・図鑑コンプ率）を `localStorage` に保存
- **超レア隠しルート**：🔮 100歳を生きた「猫又」（2本目のしっぽ）／🏮 お店で「招き猫」（小判と赤い座布団）
- 季節と場面に合わせたパーティクル（🌸✨🍂❄️💧🌈）。最期は虹の演出でフィナーレ
- 結果は `localStorage` に貯まる **転生猫図鑑** つき
- 1タップで X にシェア

静的ファイルだけで動きます（ビルド不要・外部APIなし）。

## 確率設計（ガチリアル）

| 区分 | 比率 | 内訳 |
|---|---|---|
| イエネコ | **99.0%** | 飼い猫 40% ／ 地域猫・野良猫・野生化 59% |
| 野生のネコ科 | **1.0%** | 生息数の推計比で46エントリに配分（うち2%が動物園生まれ） |

- 飼い猫のうち血統書つき純血種は **1.2%**（＝地球上の0.48%）。残りは雑種。
- 野生のネコ科は、ボブキャット（推定300万頭）だけで野生全体の約半分を占めます。
  トラ（約5,600頭）やユキヒョウ（約7,500頭）は、1万回回しても出ないことがある本当の激レアです。
- 変異は「オッドアイ」「オスの三毛猫（約3万分の1）」「多指症」「尾なし」「折れ尾」。

寿命は経過年ごとの生存率モデルで決まるため、
**生後数か月で夭折する子もいれば、20歳を超える大往生も** 普通に生まれます。
（日本飼い猫の平均は約15〜16歳、野良は3〜5年。実統計に合わせています）

## 検証

Node.js が無い環境のため、Python の埋め込みJSエンジン（quickjs）で
**ブラウザで動くのと同じ `js/*.js` を直接読み込んで** 検証しています。

```bash
python3 tests/simulate.py    # 10,000回の抽選・分布・寿命・整合性
python3 tests/ui_smoke.py    # init→ガチャ→結果→図鑑→保存 の一連
```

直近の結果（10,000回 / seed=20261123）:

- 例外 0件・アセットHTML崩れ 0件・HTMLに undefined/NaN 0件
- イエネコ 98.96% / 野生ネコ科 1.04%
- 飼い猫 40.70% / 外猫 59.30%
- 寿命：平均6.87歳・中央値5歳、15歳超 14.9%、20歳超 3.48%
- 2択イベント：94%の猫生に入り、1猫生あたり平均3.8回（長い猫生ほど多い）
- 超レア：猫又 0.15%（100歳超）／招き猫 0.50%（お店の看板猫）
- レアリティ：N 68.9% / R 26.8% / SR 3.9% / SSR 0.35% / UR 0.06%
- 経路別の平均寿命：飼い猫 11.7歳（15歳超 36%）／純血種 15.8歳／地域猫 6.2歳／野良 3.3歳／野生化 2.7歳
- 拾われる体験：26.4%の猫生で発生（地域猫 44.9% / 野良 29.3% / 野生化 9.5% / 保護施設生まれ 26.3%）
- 歩数：1歳=8歩 / 5歳=20歩 / 10歳=35歩 / 15歳=52歩 / 20歳=62歩（1x換算 3.3〜3.9分）
- 文章の重複：同じ猫生のなかで同じイベント文が出た猫 0頭
- 画像マッピング：74純血種＋46野生＋14毛柄の134エントリすべてが13タイプに紐づく

## あそびかた（やり込み）

ガチャで生まれたら、まず誕生画面で **この子がどれだけ珍しいか** を読んでください。
**「🐾 この子の猫生を歩む」** を押すと、そこから **オートで進みます**。
2択が来たらカウントダウンが始まるので、選びたければタップ。
放っておいても時間切れで自動的に選ばれて、猫生は止まらずに続きます。
選択はその場のステータスだけでなく、**その後の猫生そのもの** を変えます。

| 選択の種類 | 起きること |
|---|---|
| 延命 | `✨ ピンチを乗り越えて、長生きできそう！` 残りの猫生が延び、新しい歩みが増える（何年かは言わない） |
| 拾われる | 野良がその場で家族の猫に。首輪がついて、背景がおうちに変わる |
| ボス猫 | 縄張りを制して「👑 ボス猫」に。野良のまま10歳を超えると実績「自由の王」 |
| ピンチ | 危険な選択は稀にその場で最期に。うまく回避すると `🍀 ピンチを回避した` |

**超レア隠しルート**：15歳以上のご長寿猫がごく稀に100年を生き、**🔮 猫又** になります。
🍀運の高い子がお店に拾われると、**🏮 招き猫** として看板猫の一生を送ります。
実績は「🏆 実績・きろく」タブで確認できます。

## 画像アセット

`assets/cats/{type}-{kitten|adult}.png` の26枚。タイプは
`tabby / orange / black / white / calico / tuxedo / gray / siamese / fluffy /
lion / tiger / leopard / wildcat`。
生成→背景透過→512px軽量PNG化は `tools/` のスクリプトで再現できます。

## デプロイ

`cat-gacha/` フォルダの中身をそのまま GitHub Pages に置けば動きます
（ビルドもサーバーも不要）。

CSS/JS は `index.html` の末尾の `?v=` でキャッシュを切っています。
更新したら `?v=` を上げてください（古いJSが残ると新機能が動きません）。

## メモ

- 生息数・寿命・品種のシェアは各種統計・推計をもとにした **ゲーム内の近似値** です。
- 「その他」の国は作らず、78カ国で世界をカバーする構成にしています。
- 野生種の母数は「野生全体＝1%」に正規化しているため、表示される推定母数は
  現実の頭数そのものではなく、ガチャ内での相対的な希少度です。
