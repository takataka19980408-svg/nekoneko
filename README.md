# 🐈 世界猫生ガチャ

地球上の猫 **約10億匹** のうち、1匹に生まれ変わるシミュレーター。
家猫・地域猫・野良猫・野生化したイエネコ・野生のネコ科・動物園——ぜんぶ混ぜて、
**ガチの生息数どおりの確率**で抽選します（エンジョイ緩和モードはありません）。

- 引いた猫は、国・境遇・毛並み・性別・目の色・変異まで個体ごとに生成
- その猫の **一生（猫生ハイライト）** を0歳から享年まで自動生成
- 結果は `localStorage` に貯まる **転生猫図鑑** つき
- 1タップで X にシェア

静的ファイルだけで動きます（ビルド不要・外部APIなし）。

## ファイル構成

```
cat-gacha/
├── index.html            画面
├── css/style.css         スタイル（モバイルファースト）
├── js/
│   ├── data-core.js      全体比率・寿命プロファイル・雑種14種・変異・地域イベント
│   ├── breeds.js         純血種 74種
│   ├── wild.js           野生のネコ科 46エントリ（39種＋亜種7）
│   ├── data-countries.js 国・地域 78
│   ├── data.js           上記を統合し重みを正規化
│   ├── engine.js         抽選・寿命・タイムライン・レアリティ・表記
│   ├── svgcat.js         猫のSVGイラスト生成（種別・毛柄・目・耳が反映される）
│   └── app.js            UI（ガチャ演出・結果・図鑑・シェア）
└── tests/
    ├── simulate.py       10,000回シミュレーション検証
    └── ui_smoke.py       DOMスタブによるUIスモークテスト
```

## 確率設計（ガチリアル）

| 区分 | 比率 | 内訳 |
|---|---|---|
| イエネコ | **99.0%** | 飼い猫 40% ／ 地域猫・野良猫・野生化 59% |
| 野生のネコ科 | **1.0%** | 生息数の推計比で46エントリに配分（うち2%が動物園生まれ） |

- 飼い猫のうち血統書つき純血種は **1.2%**（＝地球上の0.48%）。残りは雑種。
- 野生のネコ科は、ボブキャット（推定300万頭）だけで野生全体の約半分を占めます。
  トラ（約5,600頭）やユキヒョウ（約7,500頭）は、1万回回しても出ないことがある本当の激レアです。
- 変異は「オッドアイ」「オスの三毛猫（約3万分の1）」「多指症」「尾なし」「折れ尾」。

寿命は経過年ごとの生存率モデルで決まるため、
**生後数か月で夭折する子もいれば、20歳を超える大往生も** 普通に生まれます。
（日本飼い猫の平均は約15〜16歳、野良は3〜5年。実統計に合わせています）

## 検証

Node.js が無い環境のため、Python の埋め込みJSエンジン（quickjs）で
**ブラウザで動くのと同じ `js/*.js` を直接読み込んで** 検証しています。

```bash
python3 tests/simulate.py    # 10,000回の抽選・分布・寿命・整合性
python3 tests/ui_smoke.py    # init→ガチャ→結果→図鑑→保存 の一連
```

直近の結果（10,000回 / seed=20261123）:

- 例外 0件・SVG崩れ 0件・HTMLに undefined/NaN 0件
- イエネコ 98.96% / 野生ネコ科 1.04%
- 飼い猫 40.70% / 外猫 59.30%
- 寿命：平均6.65歳・中央値5歳・最長27歳、15歳超 14.8%、20歳超 3.44%
- レアリティ：N 68.9% / R 26.8% / SR 3.9% / SSR 0.35% / UR 0.06%
- 経路別の平均寿命：飼い猫 11.3歳（15歳超 36%）／純血種 15.8歳／地域猫 6.0歳／野良 3.3歳／野生化 2.7歳

## デプロイ

`cat-gacha/` フォルダの中身をそのまま GitHub Pages に置けば動きます
（ビルドもサーバーも不要）。

## メモ

- 生息数・寿命・品種のシェアは各種統計・推計をもとにした **ゲーム内の近似値** です。
- 「その他」の国は作らず、78カ国で世界をカバーする構成にしています。
- 野生種の母数は「野生全体＝1%」に正規化しているため、表示される推定母数は
  現実の頭数そのものではなく、ガチャ内での相対的な希少度です。
